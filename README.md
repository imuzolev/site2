# Аудиоэкскурсия по Сити-центру

Статический сайт-аудиогид по зданию на пр. Ленина, 50 (Екатеринбург).
Пять точек маршрута, у каждой свой QR-код и аудиодорожка.

## Стек

Чистая статика: HTML + CSS + ванильный JS, без сборки.

```
index.html        — одна страница со всеми пятью точками (#point-1 … #point-5)
css/styles.css    — стили (винтажная постерная эстетика)
js/main.js        — reveal-анимации, параллакс, кастомный аудиоплеер
audio/            — MP3 по точкам маршрута
images/           — фотографии (см. images/README.txt)
```

## Локальный запуск

```bash
npx serve .
# или
python -m http.server 8000
```

## Деплой

Проект развёрнут на Vercel как статический сайт — пуш в `main` обновляет продакшн.

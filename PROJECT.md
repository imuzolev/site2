## 1. О проекте

- **Название:** sait_diplom
- **Тип:** дипломный сайт
- **Расположение:** `C:\Polina\sait_diplom`
- **Стек технологий:** статика — HTML + CSS + ванильный JS (без сборки, хостится одним каталогом)
- **Цель:** визуальное оформление аудиоэкскурсии по зданию на пр. Ленина, 50 (Сити-центр) — 5 точек, у каждой свой QR-код
- **Целевая аудитория:** посетители здания «Сити-центр» / «Центр города» в Екатеринбурге

### Ключевые требования
- 5 блоков (по числу QR-кодов), каждый — отдельный якорь `#point-1` … `#point-5`
- Кастомный аудиоплеер на каждом блоке, MP3 лежат в `audio/`
- Винтажная постерная эстетика по референсам: бордовый / кремовый / малиновый «Центр города» / тёмно-синий
- Чёрно-белые фото, плавные scroll-анимации, параллакс
- Шрифты: Cormorant Garamond (сериф + курсив), Bebas Neue (display), Unbounded (mono-labels)

### Внешние ссылки и ресурсы
- Текст экскурсии: `АУДИОЭКСКУРСИЯ ПО СИТИ-ЦЕНТРУ.md`
- Референсы дизайна: `image.png`, `image copy.png`, `image copy 2.png`

## 2. Архитектура и структура

_Опишите здесь структуру папок, ключевые модули, точки входа — по мере того как они появляются._

```
sait_diplom/
├── index.html              — единая страница со всеми 5 точками
├── css/
│   └── styles.css          — стили (винтажная постерная эстетика)
├── js/
│   └── main.js             — reveal-анимации, параллакс, кастомный аудиоплеер,
│                             прогресс-бар, подсветка точки по якорю из QR-кода
├── audio/
│   ├── README.txt          — инструкция по именованию MP3
│   └── 1-fasad.mp3 … 5-center.mp3   ← положить сюда (пока нет)
├── images/
│   ├── README.txt          — где взять и какие имена использовать
│   └── hero.jpg, point-1.jpg … point-4.jpg   ← положить сюда (пока нет)
└── АУДИОЭКСКУРСИЯ ПО СИТИ-ЦЕНТРУ.md  — исходный текст экскурсии
```

### Запуск локально
Сайт — статика, без сборки. Открыть через локальный сервер (нужен для аудио):

```
cd c:\Polina\sait_diplom
python -m http.server 8080
```
Затем открыть http://localhost:8080/

### QR-коды
Каждый код ведёт на свой якорь:
- точка 01 фасад: `<URL>/index.html#point-1`
- точка 02 клуб строителей: `<URL>/index.html#point-2`
- точка 03 киностудия: `<URL>/index.html#point-3`
- точка 04 торговый центр: `<URL>/index.html#point-4`
- точка 05 центр города: `<URL>/index.html#point-5`

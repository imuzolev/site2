Сюда положи свои фотографии. Имена должны быть точно такими:

  hero.jpg     — большое фото для главного экрана (вертикальное, ~3:4)
  point-1.jpg  — точка 01: фасад здания (вертикальное, ~7:10)
  point-2.jpg  — точка 02: интерьер клуба / архивное фото (квадрат)
  point-3.jpg  — точка 03: киностудия / кадр из фильма (вертикальное, ~7:10)
  point-4.jpg  — точка 04: торговый центр 2000-х (горизонтальное, ~3:2)
  point-5.jpg  — точка 05: «Центр города» сегодня (можно цветное)

Желательно: чёрно-белые / монохромные, с зерном и контрастом —
сайт всё равно прогонит их через CSS-фильтр grayscale, но исходник лучше тоже ч/б.

Если какого-то файла нет — сайт автоматически подгрузит серую заглушку
с picsum.photos (random photo, чтобы вёрстка не ломалась).
